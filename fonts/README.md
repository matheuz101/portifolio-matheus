# Fontes locais

Fontes obtidas na API oficial Google Fonts, em WOFF2, com subconjuntos `latin` e `latin-ext` para os textos em inglês e português:

- Cormorant variável, pesos 300–700 (Google Fonts v24).
- Manrope, peso 700 (Google Fonts v20).
- Marcellus, peso 400 (Google Fonts v14).

Para o contato e o rodapé, também foram incluídos arquivos WOFF2 oficiais de Agbalumo 400, EB Garamond 800 e Manrope 300/400. As duas novas famílias têm suas licenças em `Agbalumo-OFL.txt` e `EBGaramond-OFL.txt`; os pesos adicionais de Manrope usam `manrope-OFL.txt`.

CSS de origem das fontes de contato: https://fonts.googleapis.com/css2?family=Agbalumo&family=EB+Garamond:wght@800&family=Manrope:wght@200..800&display=swap

`fonts.css` usa caminhos locais, `font-display: swap` e os intervalos Unicode originais. Inclua este CSS para carregar as fontes sem depender de rede.

CSS de origem: https://fonts.googleapis.com/css2?family=Cormorant:wght@300..700&family=Manrope:wght@700&family=Marcellus&display=swap

Os arquivos binários foram obtidos em `fonts.gstatic.com`. As licenças SIL Open Font License 1.1 estão nos arquivos `cormorant-OFL.txt`, `manrope-OFL.txt` e `marcellus-OFL.txt`, obtidos no [repositório oficial Google Fonts](https://github.com/google/fonts/tree/main/ofl).
